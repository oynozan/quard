# Coding Guidelines

## Comments

- Keep comments short. No long comment lines.

## Formatting

- Use 4 spaces for indentation.
- Format code with Prettier.

## File size and structure

- Files must not be longer than 300 lines.
- This limit does not apply to TSX files, other web files (JSX, HTML, CSS, etc) or Markdown files.
- Use many folders to separate the different parts of the project.

## Writing style

- Use plain English in code, comments, and docs.
